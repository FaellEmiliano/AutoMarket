# AutoMarket

AutoMarket é um jogo educativo no qual o jogador aprende programação ao automatizar as operações de um mercado.

## Language

**Editor de Scripts**:
Espaço de trabalho onde o jogador cria e organiza as rotinas que automatizam o mercado, acompanha sua execução e consulta apoio didático.
_Avoid_: Tela de Scripts, IDE de Automação, Console
