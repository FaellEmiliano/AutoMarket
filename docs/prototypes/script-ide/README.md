# Protótipo descartável — IDE de scripts

Abra `index.html` no navegador. Use as setas da barra inferior ou `←` / `→` para comparar:

- `?variant=a` — Missão guiada: objetivo, progresso e feedback pedagógico ao lado do código.
- `?variant=b` — Oficina de código: experiência de IDE familiar, densa e eficiente.
- `?variant=c` — Fluxo da loja: scripts apresentados como etapas de uma automação visível.
